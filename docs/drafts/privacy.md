# 개인정보 처리방침(초안)

Magus는 원고·자료를 올려 두고 Claude가 찾아 읽게 하는 서비스입니다. 이 문서는 Magus가 어떤 정보를 어디에 얼마 동안 두는지 적은 것입니다.
시행일: (정하지 않음) · 운영자: (이름) · 문의: (메일 주소)

## 1. 모으는 것

- **로그인 메일**: 로그인할 때 로그인 서비스(WorkOS)에서 받습니다. 내 정보에 보이고, 화면 위쪽 이름으로 씁니다. 표시 이름을 적으면 그것도 둡니다.
- **올린 파일과 적은 글**: 게시판 글과 첨부, 올린 문서와 수정본, 컨텍스트, Claude 대화에서 넣은 글·결정·확인 요청.
  찾기를 위해 첨부에서 뽑은 글자와 사진의 작은 사본(썸네일)도 함께 둡니다.
- **활동 기록**: 휴지통으로 옮기기·되살리기·영구 삭제·휴지통 비우기·프로젝트 만들기·문서 업데이트를 한 시각, 동작, 대상의 종류와 번호, 어디서 했는지(웹·대화·운영자).
  이름이나 내용은 적지 않습니다. 90일이 지난 줄은 지웁니다.
- **서버 기록**: Claude가 Magus 도구를 부를 때 도구 이름, 사용자 번호, 걸린 시간, 성공 여부만 남깁니다. 찾는 말·글 내용·파일 내용은 남기지 않습니다.
  웹 접속 기록(접속한 주소·IP)은 남기지 않습니다.
- **쿠키**: 로그인을 유지하는 쿠키(12시간)와 로그인 과정에 잠깐 쓰는 쿠키(10분)만 씁니다. 광고·분석 쿠키는 없습니다.
- **도움말('?')**: 질문은 서버에 저장하지 않습니다. 이어지는 질문을 위해 대화는 내 브라우저에만 둡니다(24시간, 20번까지). 로그아웃하면 지웁니다.

## 2. 두는 곳

- 서버: Vultr 서울(대한민국).
- 백업: 매일 암호화해서 Cloudflare R2에 둡니다.

## 3. 두는 기간

- 올린 파일과 글: 직접 지울 때까지.
- 휴지통: 직접 영구 삭제하거나 휴지통을 비울 때까지(저절로 지우지 않습니다).
- 백업: 매일 백업을 30일, 그중 매달 하나를 12개월 둡니다. 그래서 지운 것도 **백업에는 최대 약 1년 남습니다**.
- 활동 기록 90일. 서버 기록은 크기가 차면 오래된 것부터 지웁니다.

## 4. 지우는 방법

- 웹에서 글·책·노드·프로젝트를 휴지통으로 옮긴 뒤, 휴지통에서 [영구 삭제]나 [휴지통 비우기]를 누릅니다. 올린 문서가 든 프로젝트는 이름을 적어야 지워집니다.
- 계정 전체를 지우려면 문의처로 알려 주세요. 운영자가 서버에서 지웁니다. 백업에서는 최대 약 1년 뒤에 사라집니다.

## 5. 외부 서비스

| 서비스 | 하는 일 | 보내는 것 |
|---|---|---|
| WorkOS(미국) | 로그인 | 메일 주소, 로그인 기록 |
| Anthropic(미국) | 웹 도움말 '?'의 답 | 적은 질문, 지금 화면 이름, 최근 질문·답 3번까지. 올린 파일·글 내용은 보내지 않습니다 |
| Cloudflare | 백업 보관(R2) | 암호화한 백업 |
| Vultr | 서버 | 모든 자료(서버에 있음) |

- Claude(claude.ai)에서 Magus를 쓰면, Claude가 도구 결과(내 글이나 첨부에서 찾은 글자)를 받아 답에 씁니다. 이 처리는 사용자의 Claude 계정 약관과 Anthropic의 정책을 따릅니다.
- 운영 알림(텔레그램)에는 서버 오류의 종류와 위치, 디스크 사용률만 갑니다. 글 내용과 개인정보는 보내지 않습니다.
