# Magus 시작 안내

Oct 9, 2026 · @이성민

『인류가 선택한 진화, 시대가 선택한 도시』 집필을 돕는 서재, Magus를 처음 쓰는 저자를 위한 안내입니다. 설정(3절)은 한 번만 하면 되고, 그 뒤로는 4절과 5절만 기억하면 됩니다. 막히면 웹 화면 오른쪽 아래의 '?'에 물어보세요.

## 1. Magus가 하는 일

Magus는 책을 쓰는 동안 생기는 것들 — 원고, 문헌, 생각, 마음에 드는 문장 — 을 Claude 대화 바깥에 안전하게 보관하는 서재입니다. Claude와 새 대화를 시작해도 **"magus 전체 보여 줘"** 한마디면 책 전체 현황을 바로 읽어 오고, 지난 대화를 다시 붙여 넣을 필요가 없습니다.

세 가지 원칙이 있습니다.

1. **원본은 언제나 Word 파일입니다.** Magus에 올린 문서는 장별로 나뉠 사본입니다. 고칠 때는 Word에서 고치고, 고친 파일을 "수정본"으로 다시 올립니다(5절).
2. **인용은 원문을 확인한 문헌만.** 저자가 원문을 읽고 "원문 확인"으로 표시한 문헌만 Claude가 인용합니다. 확인 전이면 본문에 \[출처 필요: …\]로 남깁니다. Claude가 기억에서 문헌을 지어내던 문제를 막는 장치입니다(6절).
3. **한 번에 한 장만.** Claude는 책 전체를 들고 있지 않고 필요한 장만 읽습니다. 그래서 대화가 길어져도 느려지거나 끊기지 않습니다.

**지금 서재에 있는 것** (2026-10-09 기준)

- 올린 문서 「인류가 선택한 진화, 시대가 선택한 도시」 — 수정본 E3까지 올라가 있음.
- 문헌 337편 — 참고문헌에서 들어온 것. 아직 모두 "원문 확인 전".
- 확인 요청 129건 — Word 코멘트에서 들어온 것.
- 생각·문체 책 — 대화에서 나온 생각과 마음에 드는 구절을 모아 두는 곳.

## 2. 두 창구 — Claude 대화와 웹 화면

Magus는 두 곳에서 씁니다. 둘 다 같은 서재를 보는 것이라, 웹에서 올린 것이 대화에 바로 보이고 대화에서 저장한 글이 웹에 바로 보입니다.

|  | Claude 대화 | 웹 화면 |
| --- | --- | --- |
| 어디서 | claude.ai (PC·휴대폰 앱) | magus.lifebookapplication.com (PC·휴대폰 브라우저) |
| 잘하는 일 | 장 읽기·요약, 확인 요청 보기, 인용 점검, 문헌 원문 확인 표시, 생각 저장, 찾기, 출처 확인 문서 만들기 | 지도·책장 보기, 글쓰기(사진·파일 첨부), 수정본 파일 올리기, 스크랩, 휴지통, 책 색·컨텍스트 |
| 로그인 | 커넥터를 연결할 때 한 번 | 이메일 코드, 12시간 유지 |
| 언제 | 글을 읽고 묻고 고칠 때 | 파일을 올리고 구조를 볼 때 |

평소에는 대화로 충분합니다. 웹 화면은 수정본 파일을 올리거나 사진을 붙일 때, 그리고 서재가 어떻게 생겼는지 눈으로 보고 싶을 때 엽니다.

## 3. 처음 한 번 준비

여기는 한 번만 하면 됩니다. 필요하면 성민이가 옆에서 같이 합니다.

### 3-1. Claude 계정 — 둘 중 하나

- **A. 학교 조직 계정:** 조직 관리자가 Magus 커넥터를 한 번 등록해 줘야 합니다(담당자에게 요청해 둔 상태). 등록되면 아래 3-2의 3번부터 하면 됩니다.
- **B. 개인 claude.ai 계정(Pro):** 직접 추가할 수 있습니다. 3-2를 처음부터 합니다.

어느 쪽이든 **Magus에 등록된 이메일**로 로그인해야 들어갈 수 있습니다. 다른 이메일을 쓰고 싶으면 성민이에게 말하면 등록해 줍니다.

### 3-2. 커넥터 연결 (PC 브라우저에서)

1. claude.ai에 로그인 → 왼쪽 아래 이름 → **설정** → **커넥터**.
2. "커스텀 커넥터 추가" → 이름 **Magus**, 원격 MCP 서버 URL **https://magus.lifebookapplication.com/mcp** → 추가.
3. 목록의 Magus 옆 **연결** → Magus 로그인 창이 열림 → 이메일 입력 → 메일로 온 **6자리 코드** 입력.
4. 연결되면 설정 → 커넥터 → Magus를 열어 \*\*도구 권한을 '항상 허용'\*\*으로 바꿉니다. 기본값 '승인 필요'로 두면 Claude에게 Magus 도구가 하나밖에 없는 것처럼 보여서 "전체"를 못 보여 줍니다. **이 한 줄이 가장 자주 빠뜨리는 것입니다.**
5. 새 대화를 열고 **"magus 전체 보여 줘"** → 장 목록과 확인 요청 수가 나오면 끝입니다.

### 3-3. 웹 화면 로그인

브라우저에서 **magus.lifebookapplication.com** → 이메일 입력 → 메일로 온 6자리 코드. 한 번 로그인하면 12시간 유지됩니다. 휴대폰 브라우저도 똑같이 되니 주소를 즐겨찾기에 두세요.

### 3-4. 휴대폰 Claude 앱

같은 계정으로 로그인하면 커넥터가 그대로 보입니다. 대화 입력창의 도구 메뉴(+ 또는 슬라이더 모양)에서 Magus가 켜져 있는지만 확인하세요.

### 3-5. "커넥터를 다시 연결해 달라"는 말을 들으면

Magus의 도구가 바뀔 때마다 한 번씩 필요합니다. 데이터는 그대로입니다.

설정 → 커넥터 → Magus → **연결 해제** → 다시 **연결**(이메일 코드) → **'항상 허용' 다시 확인**.

## 4. 대화로 쓰는 법

평소 말하듯 하면 됩니다. 앞에 \*\*"magus"\*\*를 붙이면 Claude가 다른 도구와 헷갈리지 않습니다. 새 대화는 언제나 "전체 보여 줘"로 시작하면 좋습니다.

| 이렇게 말하면(예) | 일어나는 일 |
| --- | --- |
| magus 전체 보여 줘 | 올린 문서의 전체 현황: 장 목록, 장별 확인 요청 수와 미확인 인용 수, 최근 결정 |
| 12장 읽어 줘 / 12장 요약해 줘 / 12장에서 이상한 데 있어? | 그 장만 읽고 답함 |
| 1장 확인 요청 보여 줘 | 그 장의 확인 요청 목록(Word 코멘트에서 온 것 포함) |
| 확인 요청 3번은 해결했어, 닫아 줘 | 닫힘. 어떻게 해결했는지 기록 남음 |
| 12장 인용 점검해 줘 | 인용을 원문 확인 / 확인 전 / 문헌에 없음으로 나눠 보여 줌 |
| 인용 질문 보여 줘 | 저자만 답할 수 있는 질문(연도 불일치, 같은 저자 두 편 등). 답하면 바로 반영 |
| 이건 이렇게 하기로 정했어, 기록해 줘 | 결정으로 남아 다음 대화에서도 보임 |
| 이 생각 「생각」 책에 저장해 줘 | 글로 저장. 책을 말하지 않으면 Claude가 어디에 넣을지 묻고, 제목을 지을지도 묻습니다 |
| 공기 밀도 에 대한 내 글 찾아 줘 | 책 전체에서 찾음(첨부 문서 속 글자까지) |
| 스크랩 보여 줘 | 웹에서 ★ 표시한 글만 |
| 지도 보여 줘 / 책장 보여 줘 | 프로젝트의 구조(노드와 책) |
| 수정본 올렸어 | 올린 파일 중 새 것을 수정본으로 가져감(5절) |
| 확인 요청을 문서로 만들어 가운데 노드에 넣어 줘 | "출처 확인 문서"가 책장에 생김: 질문, 본문과 어긋나는 곳, 사실 확인 요청, 먼저 확인할 문헌, 장별 미확인 수. 웹에서 열어 보거나 내려받아 읽습니다 |

**Claude가 하지 않는 것** — 이건 고장이 아니라 규칙입니다.

- 원문 확인이 없는 문헌을 인용하지 않습니다. 대신 \[출처 필요: …\]로 표시합니다.
- 올린 문서를 마음대로 고치지 않습니다. 수정안은 대화에서 보여 주고, 고치는 건 저자가 Word에서 합니다.
- 이유·출처·쪽수를 지어내지 않습니다. 저자가 말한 것만 기록합니다.
- 저자의 말과 Claude가 쓴 글을 구분해 저장합니다. Claude가 쓴 것에는 'AI' 표시가 붙습니다.

## 5. 원고를 고치고 올리는 흐름

가장 자주 할 일입니다. 순서는 늘 같습니다: **Word에서 고치고 → 파일을 올리고 → Claude에게 "수정본 올렸어"**.

1. **Word 원본에서 고칩니다.** 확인하고 싶은 곳에는 Word 코멘트를 달아 둡니다. 코멘트는 수정본을 올릴 때 **확인 요청**으로 들어옵니다. 지금의 확인 요청 129건도 그렇게 들어온 것입니다.
2. **저장합니다.** 파일 이름에 날짜를 넣으면 나중에 찾기 쉽습니다(예: 261015-인류가\_선택한\_진화.docx).
3. **Magus 웹에 올립니다.** magus.lifebookapplication.com → 오른쪽 위 이메일(내 정보) → **올린 파일** → **올리기** → 그 파일. (책 게시판 글에 첨부해도 됩니다.)
4. **Claude에게 말합니다.** "magus 수정본 올렸어". Claude가 가장 새 파일을 찾아 수정본(E4, E5…)으로 올립니다. 어느 파일인지 분명하지 않으면 파일 이름을 보여 주고 묻습니다.
5. **결과를 확인합니다.** "전체 보여 줘"의 수정본 줄에 새 번호가 보입니다.

수정본을 올리면 이렇게 됩니다.

- 본문이 바뀐 장만 바뀝니다. 이전 판은 이력에 남습니다(웹 올린 문서 → 수정본 이력).
- 같은 코멘트는 다시 들어오지 않습니다. Word에서 지운 코멘트는 '해결됐을 수 있음'으로 표시만 되고, 자동으로 닫히지는 않습니다. Claude가 물으면 닫으라고 하세요.
- 결정, 직접 남긴 확인 요청, 다른 책의 글은 그대로입니다.

주의할 것 둘:

- **같은 파일을 다시 올리면** "이미 올린 파일입니다"로 멈춥니다. 고친 뒤 올리세요.
- Magus에서 Word 파일을 내려받을 수는 있지만(웹 올린 문서 화면의 내려받기), 코멘트와 그림은 복원되지 않습니다. **원본은 늘 자기 파일**입니다.

## 6. 문헌과 인용 — 원문 확인

지금 문헌 337편은 참고문헌 목록에서 들어온 것이라 모두 "원문 확인 전"입니다. Claude는 이 상태의 문헌을 인용하지 않습니다. 저자가 원문을 읽고 확인해 주면 그때부터 인용합니다. 전부 할 필요는 없고, 실제로 본문에 인용된 것부터 하면 됩니다.

### 원문을 확인하는 두 가지 방법

**방법 1 — 읽고 말하기.** 원문을 읽은 뒤 Claude에게:

> magus 갤러(2022) 원문 확인했어. 쓸 부분: "…"(45쪽). 이유: 밀도와 혁신의 관계 근거.

그 문헌 글에 "쓸 부분"이 들어가고 원문 확인 표시가 붙습니다. 쓸 부분은 여러 개를 모아 둘 수 있습니다.

**방법 2 — 논문 PDF를 붙이고 찾게 하기.**

1. 웹에서 「문헌」 책의 게시판 → 글쓰기 → PDF 첨부 → 저장. (제목을 비우면 파일 이름이 제목이 됩니다.)
2. Claude에게: "magus 문헌 책의 ○○ 첨부에서 밀도 에 대한 부분 찾아 줘" → 첨부 속 글자를 찾아 앞뒤를 보여 줍니다. "그 쪽 읽어 줘"로 더 읽을 수 있습니다.
3. "그 부분을 갤러(2022) 문헌의 쓸 부분으로 저장해 줘" → 저장한 뒤 Claude가 "원문 확인 표시도 할까요?" 하고 묻습니다. 읽었으면 "응".

스캔한 PDF(글자가 아니라 그림인 것)는 찾지 못합니다. 그럴 때는 방법 1로.

### 인용 점검

- "12장 인용 점검해 줘" → 원문 확인 / 확인 전 / 문헌에 없음 세 묶음으로 보여 줍니다.
- "확인 요청을 문서로 만들어 가운데 노드에 넣어 줘" → **출처 확인 문서**가 생깁니다. 여기의 "먼저 확인할 문헌"(여러 장에서 인용된 것부터)을 차례로 해 나가면 효율적입니다.
- "인용 질문 보여 줘" → 연도가 안 맞거나, 같은 저자의 두 편 중 어느 것인지 같은 질문. 답하면 바로 반영되고 다시 묻지 않습니다.

미확인 인용은 본문에 \[출처 필요: …\]로 남아 있습니다. 이 표시는 Claude가 "나는 모른다"라고 정직하게 적은 것이니, 지우지 말고 원문을 확인한 뒤 채우세요.

## 7. 웹 화면 — 지도·노드·책·게시판

웹 화면의 구조는 큰 것에서 작은 것 순으로 이렇습니다.

**프로젝트**(책 한 권의 작업실) → **지도**(마인드맵) → **노드**(지도의 점. 열면 책장) → **책**(글이 쌓이는 공책) → **글**(제목 + 본문 + 첨부)

지금 지도는 가운데 노드에 올린 문서 「인류가 선택한 진화, 시대가 선택한 도시」가 있고, 그 주위에 「생각」·「문헌」 노드가 이어져 있습니다. 「내 서재」는 여러 책에서 같이 쓰는 자료(문체 등)를 두는 곳입니다.

| 하고 싶은 일 | 어디서 |
| --- | --- |
| 글 쓰기 | 책을 열면 게시판 → **글쓰기** → 제목·본문·첨부 → 저장. 파일은 고르거나 끌어다 놓고, 휴대폰에서는 **사진 찍기**도 됩니다(한 글에 10개, 한 파일 20MB까지). 제목을 비우고 파일만 붙이면 파일 이름이 제목이 됩니다 |
| 글 고치기 | 글을 열고 **✎ 고치기**. 첨부 옆 ✕는 휴지통으로 |
| 중요한 글 표시 | 글의 \*\*☆\*\*를 누르면 ★(스크랩). 게시판의 **★ 스크랩만**으로 모아 보고, 대화에서 "스크랩 보여 줘" |
| 찾기 | 게시판·지도·프로젝트 목록의 찾기 칸. 앞 두 글자만 쳐도, 가운데 글자만 쳐도, 파일 이름으로도, 첨부 문서 속 글자로도 찾습니다 |
| 지우기 | **휴지통으로**(🗑). 바로 사라지지 않고 지도의 **휴지통**에서 되살릴 수 있습니다. 가운데 노드와 문헌이 든 노드는 지울 수 없습니다 |
| 새 책·노드 | 노드를 열면 **+ 새 책**, 지도에서 **+ 노드**. 책 이름은 12자까지 |
| 새 프로젝트 | 프로젝트 목록의 **+ 프로젝트** → 제목 → 만들기. 올린 문서를 넣으려면 파일을 올린 뒤(올린 파일 또는 게시판 첨부) Claude에게 "「제목」의 올린 문서로 가져와 줘" |
| 책 설정 | 게시판의 **⚙ 책 설정**: 이름·색·컨텍스트·위치 |
| 수정본 파일 올리기 | 오른쪽 위 이메일(내 정보) → **올린 파일** → 올리기(5절) |
| 올린 문서 보기 | 가운데 노드의 책: 장 목록 · 확인 요청 · 인용 상태 · 수정본 이력 · 내려받기 |
| 전부 내려받기 | 프로젝트 목록의 **전체 내려받기** → 글 전부가 텍스트 파일로 묶인 zip |
| 모를 때 | 오른쪽 아래 **?** → "글은 어떻게 고쳐요?"처럼 물어보세요. 창을 닫아도 대화가 남습니다 |

**컨텍스트**는 책이나 노드에 적어 두는 "이 글을 읽는 방법"입니다. 예를 들어 「문체」 책에는 "문학적 부분이 마음에 드는 구절을 모아 놓은 것. 내 문장 표현을 다듬을 때 사용"이 적혀 있습니다. Claude는 그 책의 글을 읽거나 넣을 때 이 문장을 먼저 읽습니다. 자주 쓰는 것은 이름을 붙여 "자주 쓰는 컨텍스트"로 모아 두고 여러 책에 붙일 수 있습니다.

첨부한 docx·pdf·txt는 올릴 때 글자를 뽑아 두어서 찾기와 Claude 읽기가 됩니다. 무엇이 뽑혔는지는 글 보기의 **글자 보기**로 확인할 수 있습니다. 사진과 스캔본은 글자를 뽑지 않습니다.

## 8. 용어 한 장

Claude도 웹 화면도 같은 말을 씁니다.

| 말 | 뜻 |
| --- | --- |
| 프로젝트 | 작업물 하나. 올린 문서와 그 자료를 묶음 |
| 내 서재 | 여러 프로젝트가 함께 쓰는 자료를 두는 곳 |
| 지도 | 프로젝트의 마인드맵. 노드와 선 |
| 노드 | 지도의 한 점. 열면 책장. 가운데 노드는 올린 문서의 자리 |
| 연결 노드 | 다른 프로젝트(예: 내 서재)의 노드를 가리키는 노드 |
| 책장 | 노드를 열면 보이는, 책이 꽂힌 칸 |
| 책 | 노드에 꽂힌 묶음. 안에 글이 쌓임 |
| 글 | 책에 쌓인 것 하나. 제목 + 본문 + 첨부 |
| 게시판 | 책을 열면 보이는 글 목록 |
| 컨텍스트 | 책·노드에 저자가 적어 둔 "이 글을 읽는 방법" |
| 자주 쓰는 컨텍스트 | 이름을 붙여 모아 둔 컨텍스트. 여러 책에 붙임 |
| 올린 문서 | 가운데 노드에 올린 Word·PDF. 장·확인 요청·참고문헌·수정본 이력이 있음. 원본은 저자의 파일 |
| 전체 | 올린 문서의 전체 현황(구성과 상태. 전문이 아님) |
| 확인 요청 | 출처·사실을 확인해야 하는 곳. Word 코멘트에서 들어오거나 직접 남김. AI가 단 것은 'AI 확인 요청' |
| 결정 | 정해 둔 방침 |
| 수정본 | 원본 파일에서 고친 문서를 다시 올린 것. E2, E3…은 수정본 번호 |
| 원문 확인 | 저자가 원문을 읽고 확인한 문헌 글에 붙는 표시. 이것만 인용됨 |
| 쓸 부분 | 문헌에서 저자가 고른 대목(이유·쪽수와 함께) |
| 출처 확인 문서 | 질문·불일치·먼저 확인할 문헌을 모아 만든 읽기용 문서 |
| 스크랩 | ★로 표시해 둔 글 |
| 휴지통 | 지운 것이 가는 곳. 되살릴 수 있음 |

## 9. 문제가 생기면

| 이런 일이 | 이렇게 |
| --- | --- |
| Claude가 "Magus 도구가 하나뿐"이라거나 "전체를 보여 줄 수 없다"고 함 | 설정 → 커넥터 → Magus → 도구 권한을 \*\*'항상 허용'\*\*으로. 가장 흔한 일 |
| Claude가 "Magus가 연결돼 있지 않다"고 함 | 설정 → 커넥터 → Magus 연결 해제 → 다시 연결 → '항상 허용' 확인(3-5) |
| Claude가 Magus를 안 부르고 기억으로 대답함 | 앞에 "magus"를 붙여 다시 말하기. 새 대화라면 "magus 전체 보여 줘"부터 |
| 대화가 길어져 느려짐 | 새 대화 → "magus 전체 보여 줘". 지난 대화를 붙여 넣을 필요 없음 |
| 웹 화면 로그인이 풀림 | 12시간마다 다시 로그인하는 게 정상 |
| 실수로 지움 | 지도의 휴지통에서 되살리기 |
| "이미 올린 파일입니다" | 같은 파일을 두 번 올린 것. Word에서 고친 뒤 다시 |
| 웹이 안 열리거나 이상함 | 성민이에게. 서버는 5분마다 감시되고 데이터는 매일 새벽에 백업되니 잃어버릴 일은 없음 |
| 웹 화면에서 무엇을 눌러야 할지 모름 | 오른쪽 아래 \*\*?\*\*에 말로 묻기 |

## 10. 꼭 지킬 것 몇 가지

1. **원본은 Word 파일.** Magus 안의 글을 믿고 원본을 버리지 마세요. Magus는 사본과 기록을 맡습니다.
2. **수정본은 고친 파일을.** 올리기 전에 Word에서 저장했는지 확인.
3. **\[출처 필요\]는 지우지 말고 채우기.** Claude가 모른다고 정직하게 적은 자리입니다.
4. **"원문 확인"은 저자만.** Claude가 대신 확인해 주지 않습니다. 그게 이 서재의 방식입니다.
5. **새 대화는 "magus 전체 보여 줘"부터.** 그러면 Claude가 책을 알고 시작합니다.
6. **모르면 묻기.** 웹의 '?'에, 아니면 성민이에게.
