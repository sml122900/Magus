# Claude에 Magus 연결하기 (초안)

> **초안이다.** 6단계(배포 후)에서 실제 화면을 보며 고친다. 화면 이름은 Claude 도움말(2026-10)을 따랐고, 아직 직접 확인하지 않았다.
> 운영자는 배포를 마치고 아래 "운영자가 미리 할 일"을 끝낸 뒤 이 문서를 확정한다.

## 운영자가 미리 할 일

- [ ] 서버 주소가 열려 있다: `https://<도메인>/healthz` → ok
- [ ] 운영자 본인이 `ALLOWED_USERS`에 `=default`로 들어 있다(docs/deploy.md 2-1절). 아버지는 7단계에서 `=father`로 추가한다([onboarding-father.md](onboarding-father.md))
- [ ] 커넥터 URL: `https://<도메인>/mcp`

---

## 사용자용(개발자)

1. claude.ai(웹) → 설정 → 커넥터 → **커스텀 커넥터 추가**
2. 이름 `Magus`, URL `https://<도메인>/mcp`
3. 고급 설정의 클라이언트 등록 방식은 **"Claude의 공개 신원 사용"(CIMD, 권장)**으로 둔다. 연결한 뒤에는 바꿀 수 없다(바꾸려면 지우고 다시 추가).
4. 연결 → WorkOS 로그인 화면 → 로그인 → Claude로 돌아온다
5. 새 대화에서 확인한다(웹, 그다음 모바일 앱에서 같은 것)
   - "Magus의 book_outline을 호출해 줘" → 첫 줄 `프로젝트: 닿으려는 종 (book)`
   - "idea_add로 '연결 시험 메모'를 기록해 줘" → `기록함 [me] …`
   - "ref_search로 '인구'를 찾아 줘" → verified 문헌이 없으면 "결과 없음"이 정상이다
6. **토큰 갱신 확인**(알려진 위험): 다음 날 같은 대화에서 다시 불러 본다. 로그인을 다시 하라고 하면 기록한다.

## 아버지용

1. 컴퓨터에서 claude.ai에 로그인한다.
2. 왼쪽 아래 이름 → **설정** → **커넥터** → **커스텀 커넥터 추가**를 누른다.
3. 이름에 `Magus`, 주소에 `https://<도메인>/mcp`를 넣고 **추가**를 누른다. 나머지 칸은 그대로 둔다.
4. **연결**을 누르면 로그인 화면이 나온다. 초대 메일을 받은 주소(또는 Google)로 로그인한다.
5. 휴대폰 Claude 앱에서는 따로 할 일이 없다. 컴퓨터에서 연결한 것이 그대로 보인다.
6. 새 대화에서 이렇게 말해 본다.
   - "책 지도를 보여 줘" → 목차와 미확인 문헌 수가 나온다
   - "제12장 인용 중 확인 안 된 것 알려줘" → 문헌 목록이 나온다
   - "오늘 떠오른 생각을 기록해 줘: …" → "기록함"이 나온다

파일(원고 docx, 논문 PDF)은 브라우저에서 `https://<도메인>/inbox`에 올린다. 같은 계정으로 로그인한다.
