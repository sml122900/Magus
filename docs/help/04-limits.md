# 한도와 규칙

## 개수
- 프로젝트: 「내 서재」 빼고 20개.
- 노드: 프로젝트마다 40개(가운데 노드·연결 노드 포함). 노드 하나에 책 12권.
- 책: 사람마다 60권(올린 문서와 만든 문서는 세지 않음).
- 내 색: 12개.
- 컨텍스트: 노드·책 하나에 4개. 자주 쓰는 컨텍스트 20개.
- 첨부: 한 번에 10개.

## 길이
- 책 이름 12자(책등에 세로로 들어가는 길이). 노드 이름 20자. 프로젝트 제목 120자. 표시 이름 40자.
- 글 제목 80자, 본문 2만 자.
- 컨텍스트 이름 20자, 내용 500자. 노드와 책의 컨텍스트는 합쳐 1,000자까지 AI에게 보입니다.

## 파일 크기와 형식
- 올린 문서(docx·pdf)와 올린 파일(docx·pdf·md·txt): 한 개 50MB.
- 첨부: 한 개 20MB(운영자가 바꿀 수 있음). 받는 형식은 문서(pdf, docx, doc, hwp, hwpx, odt, rtf, txt, md), 표(csv, xlsx, xls, ods), 발표 자료(pptx, ppt, odp), 그림(png, jpg, jpeg, gif, webp, heic, heif, tif, tiff)입니다. 실행 파일·웹 페이지·svg 같은 형식은 받지 않습니다.
- 파일 이름: 폴더 구분자(/, \)나 특수 문자(: * ? " < > |)가 있거나 점으로 시작하는 이름은 받지 않습니다. 브라우저가 붙인 폴더 이름은 떼고 파일 이름만 씁니다.
- 저장 용량: 사람마다 1,000MB(올린 문서·첨부·올린 파일·휴지통 모두 포함). 사용량은 올린 파일 화면에 보입니다.

## 쓸 수 없는 이름
- 책 이름으로 '전체', '확인 요청', '결정', '수정본', '책장', '프로젝트', '지도', '노드', '연결 노드', '내 서재', '게시판', '컨텍스트', '휴지통' 같은 정해진 이름은 쓸 수 없습니다. 같은 프로젝트에 이미 있는 책 이름도 쓸 수 없습니다.

## 옮기거나 지울 수 없는 것
- 올린 문서는 가운데 노드 자체라 다른 노드로 옮기지 않습니다. 다른 문서면 새 프로젝트를 만들어 올립니다.
- 가운데 노드의 이름은 프로젝트 제목입니다. 연결 노드의 이름은 원본 노드 이름을 따릅니다.
- 같은 프로젝트의 노드끼리는 연결 노드를 만들지 않고 선으로 잇습니다.
- 휴지통으로 옮기지 않는 것: 가운데 노드, 다른 프로젝트가 연결하고 있는 노드, 문헌 글, 문헌 글이 든 책(과 그 책이 꽂힌 노드). 휴지통에서 아주 지우는 기능은 없습니다.
- 되돌리기는 마지막으로 옮긴 것 하나만 됩니다.

## 보안과 내 자료
- 로그인한 본인의 자료만 보입니다. 다른 사람의 프로젝트·글·첨부는 주소를 알아도 열리지 않습니다.
- 내려받기 링크는 24시간 뒤 만료되고, 같은 사람으로 로그인해 있어야 받을 수 있습니다.
- 로그인은 12시간 유지됩니다.
- 자료는 매일 백업됩니다(첨부 포함).
