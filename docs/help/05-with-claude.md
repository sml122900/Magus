# Claude 대화로 하는 일

Magus는 claude.ai(웹·휴대폰·데스크톱)의 커넥터로 연결해 Claude와 함께 씁니다. 화면에 없는 일은 대화에서 Claude에게 부탁합니다. Claude는 노드·책의 컨텍스트를 따라 글을 읽고 넣습니다.

## 이렇게 말하면 됩니다
- "전체 보여 줘": 올린 문서의 전체 현황(구성·상태)을 봅니다. 올린 문서 전문을 한꺼번에 보이지는 않고, 한 번에 한 장씩 봅니다("3장 보여 줘").
- "수정본 올렸어": 고친 문서를 게시판 글에 첨부해 두고(또는 올린 파일에 두고) 말하면, Claude가 그 문서를 찾아 이 프로젝트의 수정본으로 올립니다. 어느 파일인지 분명하지 않으면 파일 이름을 보여 주며 묻습니다.
- "이 문서를 올려 줘": 제목만 만든 프로젝트에, 게시판 글에 첨부한 문서를 올린 문서로 가져옵니다.
- "지도 보여 줘", "책장 보여 줘": 프로젝트의 노드와 책 목록을 봅니다.
- "「사례」 노드 만들어 줘", "내 서재의 문체를 이 프로젝트에 연결해 줘": 노드와 연결 노드를 만듭니다.
- "「생각」 책에 넣어 줘: …", "이 문장 문체 책에 저장해 줘": 그 책에 글로 넣습니다. 어디에 넣을지 말하지 않고 "저장해 줘"라고만 하면, Claude가 책 이름과 컨텍스트 이름을 보여 주며 어디에 넣을지 먼저 묻습니다.
- 글의 제목을 말하지 않으면 Claude가 직접 지을지·지어 드릴지·비워 둘지 묻습니다. "앞으로는 제목을 지어 줘"처럼 정해 두면 그 뒤로는 묻지 않습니다.
- "이 논문을 「읽은 논문」 책에 원문 확인으로 넣어 줘. 쓸 부분은 「…」, 이유는 …": 원문 확인 문헌 글로 넣습니다. 쓸 부분과 이유는 저자가 말한 것만 넣습니다.
- "올린 파일 kremer1993.pdf를 문헌으로 등록해 줘": 올린 파일의 원문을 그 문헌에 붙입니다.
- "Clack(2012) 원문 확인 표시 떼 줘", "다시 붙여 줘": 원문 확인 표시만 바꿉니다(쓸 부분·서지는 그대로). 저자가 분명히 말했을 때만 합니다.
- "이 대화 기록을 「생각」 책에 넣어 줘": 대화 기록을 저자의 말과 AI의 답으로 나눠 넣습니다.
- "이 문서 인용 확인하고 나에게 물어볼 것 정리해서 「… 출처 확인 문서」로 만들어 이 노드에 넣어 줘": 올린 문서에서 출처 확인 문서를 만듭니다. 질문·수치·문헌 목록은 Magus가 올린 문서와 문헌에서 그대로 만들고, Claude는 원하시면 머리말만 붙입니다.
- "답해 주실 질문 보여 줘", "그 연도는 본문을 고칠게": 답해 주실 질문에 답합니다. 표기를 잇는 답은 바로 반영되고, "Word에서 고칠게" 같은 답은 결정으로 남아 '원본 반영 대기'가 됩니다.
- "I3 닫아 줘", "3장에 확인 요청 남겨 줘", "이렇게 하기로 정했어: …": 확인 요청을 닫거나 남기고, 결정을 남깁니다.
- "「사례」 책 지워 줘", "그 글 지워 줘": 휴지통으로 옮깁니다(여러 개면 목록을 보여 주고 확인받습니다).
- "그 글 제목을 …로 고쳐 줘", "그 글 본문에 …를 더해 줘": 웹에서는 글을 고치지 않으므로 고칠 것은 Claude에게 말합니다.

## 알아 두면 좋은 것
- 올린 문서의 원본은 저자의 파일(Word 등)입니다. Claude의 수정안은 대화에서 받고, 저자가 원본 파일에 반영한 뒤 수정본으로 올립니다. Magus의 올린 문서에 바로 저장하는 것은 저자가 그렇게 하라고 분명히 말했을 때만 합니다.
- Claude는 원문 확인 문헌의 쓸 부분만 인용합니다. 확인되지 않은 출처는 본문에 [출처 필요: 주장 요약]으로 남깁니다. 기억에 있는 문헌이라도 원문 확인 글이 없으면 인용하지 않습니다.
- 저자의 말과 AI의 말을 구분해 남깁니다. 찾을 때는 저자의 말을 먼저 보입니다.
- 첨부는 Claude가 평소에 이름·종류·크기만 봅니다. 저자가 "수정본 올렸어"·"이 문서를 올려 줘"·"이 논문을 문헌으로 등록해 줘"처럼 말하면 그 문서(docx·pdf·md·txt)만 가져옵니다.
- 프로젝트가 여럿이면 Claude는 대화에서 다루는 프로젝트에 넣고, 분명하지 않으면 어느 프로젝트인지 묻습니다. 「내 서재」에는 저자가 '내 서재'라고 말했을 때 넣습니다.
- 대화 화면에 Magus 기능이 안 보이면 claude.ai의 커넥터 설정에서 Magus를 켜고, 바뀐 뒤에는 연결을 끊었다가 다시 연결합니다.
