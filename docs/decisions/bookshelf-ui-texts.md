옛 `/issues`·`/checklist`·`/questions` 화면에서 그대로 옮긴 문구(확인 요청 표, 신호등, 질문 카드 등)는 빼고 **새로 생기거나 바뀐 것만** 적는다.

- 고친 뒤: "「이름」 책을 고쳤습니다."(원고 책·문서 책). 휴지통으로 옮긴 뒤: "책을 휴지통으로 옮겼습니다. 지운 것이 아니라 운영자가 되살릴 수 있습니다."
