# 인용 매칭 보정: 고유 문헌 수 집계, 음역 추정, uncertain, 동명·연도 모호

- 날짜: 2026-10-03 (실원고 보정 라운드)
- 단계: 4단계 보정(실데이터) + 검토 결정 #17 변경
- 코드: `src/magus/melchior/{citations,check,translit,report,bibliography}.py`, `tests/test_realdata_shapes.py`, `tests/test_citations.py`

## Problem

- **사용자 결정 #17 변경**: 미확인 인용 수는 출현 횟수가 아니라 **고유 문헌 수**로 센다(장별·전체). ref_check 응답에는 문헌별 출현 위치를 함께 준다.
- 실원고 본문의 인용 422개 중 기존 추출기가 놓친 형식들(43건):
  - 발음 부호(Araújo, Prüfer, Myrskylä, Giráldez), 소문자 접두어(de Vries, von Glahn, della Paolera, & van Zanden)
  - 여러 단어 저자(Ibn Khaldun, Korea JoongAng Daily), 한자 저자(田代和生)
  - 설명 뒤에 붙은 인용(`(1990년 국제달러, Maddison, 2001)`), 연도 범위(`(Toynbee, 1934–1961)`)
- 한국어 서술형 인용: `케인스(1930)`, `하야시(2016)`, `모리스(2010)`, `넌·첸(2011)`, `김성은·테르틸트·염민철(2024)`, `셰 등(2019)`.
  - 참고문헌은 영문이고 `[국역: 『…』]`에 한글 저자명이 없어 aliases로 이을 수 없었다.
- 오탐
  - 지명·사건·통계: `모스크바 회사(1555)`, `합계출산율(2023)`, `마닐라(1571)`
  - 한글 낱말 + 라틴 공저자: "대사량 배수, Hu et al.(2023)" → `배수2023`
  - 조사 제거가 실명을 자름: `김성은` → `김성`
- 같은 저자·같은 연도 문헌: Acemoglu 2001 두 편, Keynes 1930a·1930b.

## Action

- **추출기**
  - 라틴 이름은 발음 부호·소문자 접두어·1~3단어를 허용한다. 한자 이름은 한자 그대로 key로 쓴다.
  - 괄호 조각 끝의 "이름, 연도"를 찾는다. 앞에 설명이 있어도 되고, 연도 범위는 괄호 인용에서만 받는다.
  - **공저자 꼬리는 첫 저자의 문자 체계를 따른다**(라틴 뒤에는 라틴, 한글 뒤에는 `·`/`와·과`). 한 글자 한글 성은 `등`·`외`·`·`이 뒤따를 때만 받는다.
  - 조사는 이름 끝에 올 수 없는 것(는·를·에서…)만 뗀다. 은·이·가·의·도·로·만은 실명에 흔해서 떼지 않는다.
  - 띄어 쓴 일본·중국 이름(`다시로 가즈이(1981)`)은 앞 낱말과 붙인 후보도 만든다.
  - 지명·기관·사건 접미사(회사·동맹·함락·출산율·시장…)와 일반명사(종합서·저서·논문…)는 저자로 보지 않는다.
- **해석 순서**: key → aliases → (한글 표기만) 같은 연도 문헌과 **음역 추정**.
  - 음역 추정: 자음 골격(소리 갈래)을 비교하고, 같은 연도 후보 중 0.75 이상인 하나를 고른다. 동점이면 고르지 않는다.
  - 한국인 저자는 성씨 로마자 표기표로 맞춘다(김→Kim). 독일식 W는 v 소리 변형도 비교한다.
- 한글 표기인데 어디에도 이어지지 않으면 **uncertain**으로 따로 둔다. 인명이면 aliases가 필요하고, 지명·사건이면 무시하면 된다. 이것은 미확인 수에 넣지 않는다.
- **동명·연도 모호**
  - 같은 key 형제(`acemoglu2001`, `-2`)는 인용의 공저자 이름으로 가린다.
  - `Keynes(1930)`인데 참고문헌에 1930a·1930b만 있으면 첫 항목으로 잇고 "연도 a/b 모호"로 표시한다.
- **집계**
  - 장별 `unverified_cite_count` = 고유 문헌 수(unverified + unknown).
  - ref_check 응답: 문헌별 `count`·`cited_as`·`paragraphs`(장 본문의 문단 번호)·`matched_by`, `uncertain` 목록, `unique_unchecked`.
- **책 전체 리포트**(`magus cite-report --project-id book`)
  - 전체·장별 고유 미확인 수, 많이 인용된 순위(출현·등장 장)
  - 참고문헌에 없는 인용(같은 저자의 다른 연도 힌트 포함), uncertain, 추정 연결 목록, 참고문헌 중 미인용
- 참고문헌의 한자 이름 + 한글 읽기(`田代和生(다시로 가즈이)`)는 key를 한자로 하고, 읽기의 성과 전체를 aliases로 넣는다.
- 비교한 대안
  - **한글 표기를 모두 unknown으로 두기**: 실제로는 참고문헌에 있는데 "없음"으로 보고된다(케인스·모리스·넌 등).
  - **음역을 aliases에 자동 저장**: 추정이 틀리면 원본(파일)을 오염시킨다. 그래서 검사할 때만 추정하고 표시한다.
  - **지명 사전**: 고유명사가 끝이 없고, 이 책의 지명은 대부분 외래어 음역이라 인명과 구별되지 않는다.
