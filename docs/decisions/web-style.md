# 웹 화면 스타일 (2026-10-06)

## Problem

- 웹 화면(`/book`·`/inbox`·`/issues`·`/checklist`, 세 책장 `/ideas`·`/refs`·`/styles`)은 브라우저 기본 모양이었다. 주 사용자는 고령의 저자(아버지)라 글이 작고, 버튼과 입력칸이 잘 보이지 않았다.
- 제약
  - 결정 #56: 템플릿 엔진·외부 글꼴·CDN 없이 서버에서 그린 HTML. 스타일은 `web.py`의 `STYLE` 상수 한 곳에 둔다.
  - 화면 문구는 바꾸지 않는다(문구 변경은 사용자 결정으로만. 용어 통일 #85가 그 예다).
  - 휴대폰(폭 390px)에서도 읽히고 눌려야 한다.
- 출발점: 외부 디자인 분석 문서(private/design)의 색·모서리·간격 토큰. 이 문서는 홍보 페이지용이라 그대로 쓰면 작업 화면에서 읽기 어렵다(가는 글씨, 15px 본문, 그라데이션 배경).

## Action

**선택: 참고 문서의 색·모서리·간격 토큰만 가져오고, 글꼴·굵기·크기·대비는 가독성 기준으로 다시 정했다.**

### 책 음영(어떤 책 색에서도 글자 대비를 낮추지 않게)

- 양 끝을 반투명 검정(30%·28%)으로 어둡게 해 둥근 책등처럼 보인다. 이름은 가운데라 끝 음영과 겹치지 않는다.
- 천·종이 결(가로 3.5%·세로 2.5%), 위아래 띠(22%), 가운데 밝은 줄(14%, 글자가 짙을 때만)은 **글자와 반대 방향으로만** 얹는다: 글자가 흰색이면 검정을, 짙으면 흰색을 얹는다. 그래서 띠·결 위 글자의 대비는 책 색 바탕일 때보다 낮아지지 않는다.
- 띠의 가는 선은 글자색 45%다.
- 마우스를 올리거나 키보드로 고르면 14px 뽑혀 나온다. `prefers-reduced-motion`이면 움직이지 않고 3px `--primary` 테두리만.

### 게시판형 목록

- 한 줄 = 제목(17px, 600) · 작성 시각(날짜와 시:분, `--ink2`, 숫자 폭 고정) · 보조 정보(15px). 데스크톱은 세 칸 격자라 시각 칸이 줄마다 맞는다. 휴대폰은 제목 한 줄, 그 아래 시각·보조 정보.
- 제목이 없으면 내용 앞부분 80자를 `--mute`(흰 바탕 4.75:1)로 흐리게 보인다. 펼친 항목은 왼쪽에 4px `--primary` 띠.
- AI가 지은 제목은 제목 뒤 알약 "AI가 지은 제목"(14px, 태그 색 6.2:1).

대안을 버린 이유: 참고 문서를 그대로 옮기면 가는 15px 글씨와 흐린 입력칸이 고령 사용자에게 읽히지 않고, CSS 프레임워크는 #56(CDN 없음)과 맞지 않으며 화면 일곱 개에는 과하다.

## 책장 3D(2026-10-07, #93 → 같은 날 밤 다시 만듦 → 10-08 한 화면·시점 조정)

책장 전체(`/shelf`)는 **하나의 장**을 위쪽에서 비스듬히 본 모습이다(정면·오른쪽 옆면·윗면). 값은 `magus/webfloors.py`의 `FLOOR_STYLE` 한 곳에만 있다(책장 전용).
구도는 사용자가 준 시안 `private/design/bookcase-3d-prototype.html`(채팅 Claude가 만든 구도 시안)을 따른다.

- 구조: 바깥 틀(양옆 기둥·윗판·오른쪽 옆판·윗면)은 한 번만 그리고, 층은 그 안의 칸이다. 칸마다 뒤판·바닥판·왼쪽·오른쪽 안벽·천장이 있어 깊이가 있다.
  책은 앞면(책등: 종류 띠·이름·아래 숫자·옛 판 기준 띠)·오른쪽 면·윗면(종이)이 있는 상자로 칸 안(앞면에서 14px 안쪽)에 선다.
  한 칸에 책이 많으면 보조 선반을 넣고 다음 줄에 세운다(줄 바꿈 자리는 서버가 책 폭으로 데스크톱·모바일 따로 계산).
- 각도(10-08, 사용자 판단 "기울기가 커서 글자가 잘 안 보인다"): 전체 보기 rotateX(-8°) → rotateY(-15°), 원근 1600px. 층 확대 rotateX(-4°) → rotateY(-6°),
  그 층이 본문 너비의 94%를 채우게 확대(데스크톱 약 1.8배). 모바일(700px 이하) 전체 rotateX(-6°)·rotateY(-10°), 확대 -3°·-4°, 원근 1100px.
  깊이 150px(모바일 80px), 장 너비 600px(모바일 300px). (그 전: -16°·-30°, 원근 1500px, 확대 때 회전 0)
  층이 다섯을 넘으면 기울기를 5/층 수로 줄이고(0.4배까지) 원근 거리를 층마다 160px 늘린다(긴 장의 위아래 크기 차이를 줄이려고).
  **이름표가 장과 함께 기우는 것은 의도다. "기울어 보인다"는 이유로 원근을 펴지 않는다**(2026-10-07 사용자 판단. 처음 #93에서 3~6° 기운다며 원근을 5200px로 편 것이 '거의 정면·얇은 옆면·층마다 따로 그린 액자'의 원인이었다).
- 색(면마다 밝기를 달리한다: 윗면 밝게, 옆면 어둡게, 칸 안쪽 가장 어둡게): 앞면 나무 #8a5a32(기둥·윗판), 선반 앞판 #7f5130, 윗면 #a9764a, 옆판 #6a4325,
  칸 뒤판 #3a2617, 안벽 #5a3b22, 천장 #2c1d12, 바닥판 #9b6a3f, 책 윗면(종이) #efe4cc, 책 오른쪽 면은 책 색에 검정 36%. 나무결은 2px 줄무늬(그라데이션은 책장 전용 범위 안).
- 글자: 선반 앞판 이름표 "층 이름 · 작업물 제목 … 최근 수정"(15px·600 #fbf3e3 = 6.1:1, 최근 수정 14px #f3e6cc = 5.45:1, 모바일 14px·12px). 길면 제목을 말줄임.
