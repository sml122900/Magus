# 웹 화면 스타일 (2026-10-06)

## Problem

- 웹 화면(`/book`·`/inbox`·`/issues`·`/checklist`, 세 책장 `/ideas`·`/refs`·`/styles`)은 브라우저 기본 모양이었다. 주 사용자는 고령의 저자(아버지)라 글이 작고, 버튼과 입력칸이 잘 보이지 않았다.
- 제약
  - 결정 #56: 템플릿 엔진·외부 글꼴·CDN 없이 서버에서 그린 HTML. 스타일은 `web.py`의 `STYLE` 상수 한 곳에 둔다.
  - 화면 문구는 바꾸지 않는다(문구 변경은 사용자 결정으로만. 용어 통일 #85가 그 예다).
  - 휴대폰(폭 390px)에서도 읽히고 눌려야 한다.
- 출발점: 외부 디자인 분석 문서(private/design)의 색·모서리·간격 토큰. 이 문서는 홍보 페이지용이라 그대로 쓰면 작업 화면에서 읽기 어렵다(가는 글씨, 15px 본문, 그라데이션 배경).

## Action

**선택: 참고 문서의 색·모서리·간격 토큰만 가져오고, 글꼴·굵기·크기·대비는 가독성 기준으로 다시 정했다.**

### 책 음영(어떤 책 색에서도 글자 대비를 낮추지 않게)

- 양 끝을 반투명 검정(30%·28%)으로 어둡게 해 둥근 책등처럼 보인다. 이름은 가운데라 끝 음영과 겹치지 않는다.
- 천·종이 결(가로 3.5%·세로 2.5%), 위아래 띠(22%), 가운데 밝은 줄(14%, 글자가 짙을 때만)은 **글자와 반대 방향으로만** 얹는다: 글자가 흰색이면 검정을, 짙으면 흰색을 얹는다. 그래서 띠·결 위 글자의 대비는 책 색 바탕일 때보다 낮아지지 않는다.
- 띠의 가는 선은 글자색 45%다.
- 마우스를 올리거나 키보드로 고르면 14px 뽑혀 나온다. `prefers-reduced-motion`이면 움직이지 않고 3px `--primary` 테두리만.

### 게시판형 목록

- 한 줄 = 제목(17px, 600) · 작성 시각(날짜와 시:분, `--ink2`, 숫자 폭 고정) · 보조 정보(15px). 데스크톱은 세 칸 격자라 시각 칸이 줄마다 맞는다. 휴대폰은 제목 한 줄, 그 아래 시각·보조 정보.
- 제목이 없으면 내용 앞부분 80자를 `--mute`(흰 바탕 4.75:1)로 흐리게 보인다. 펼친 항목은 왼쪽에 4px `--primary` 띠.
- AI가 지은 제목은 제목 뒤 알약 "AI가 지은 제목"(14px, 태그 색 6.2:1).

대안을 버린 이유: 참고 문서를 그대로 옮기면 가는 15px 글씨와 흐린 입력칸이 고령 사용자에게 읽히지 않고, CSS 프레임워크는 #56(CDN 없음)과 맞지 않으며 화면 일곱 개에는 과하다.

## 책장 3D(2026-10-07, #93)

책장 전체(`/shelf`)는 정면·오른쪽 옆면·윗면이 보이는 비스듬한 장이다. 값은 `magus/webfloors.py`의 `FLOOR_STYLE` 한 곳에만 있다(책장 전용).

- 색: 나무·선반·뒤판은 "책장 전용" 색 그대로. 옆면은 짙은 나무(#6a4122 → #55331a), 윗면은 밝은 나무(#b38559 → #986741). 그라데이션은 나무 면에만 쓴다(화면 전체 규칙 '그라데이션 없음'의 예외는 책장 전용 범위 안).
- 각도: 데스크톱 rotateY(-18°) → rotateX(-6°), 원근 5200px, 깊이 120px. 모바일(767px 이하) rotateY(-11°) → rotateX(-5°), 원근 3200px, 깊이 52px.
  회전 순서(Y 바깥, X 안쪽)와 긴 원근 거리는 **가로 글자(층 이름·작업물 제목·최근 수정)를 수평으로 두려고** 고른 것이다.
  처음 값(rotateX → rotateY, 원근 1700px, 시점 위쪽)은 선반 오른쪽 글자가 3~6° 기울었다(캡처 `private/screens/2026-10-07-floors/draft/`).
- 글자: 층 이름 19px·600, 작업물 제목 17px·600(길면 말줄임, 전체 제목은 title·낭독기 이름에), 최근 수정 15px(#3d3326, 선반 가장자리 바탕 위 6.5:1 이상. 층 이름·제목 #1a1a1a는 9.2:1 이상).
  작은 책의 이름 15px 세로쓰기(책 색 위 글자색은 큰 책과 같은 규칙).
- 움직임: 층을 누르면 0.65초 다가가기(다른 층·옆면·윗면은 0.4초에 걸쳐 사라짐), 화면 사이는 문서 전환 0.28초.
  `prefers-reduced-motion: reduce`면 다가가기·전환·떠오름이 모두 꺼지고 바로 넘어간다.
- 마우스를 올리면 층이 조금 밝아지고(brightness 1.1) 흰 테두리 3px. 끌 때 받는 층은 보라(--primary) 테두리 4px, 한 층 화면의 층 이름 띠는 보라 바탕·흰 글자.
