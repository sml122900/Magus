# 층 구조 → 프로젝트·마인드맵(지도) — 사용자 결정 #95 (2026-10-08, 확인 대기)

> #93(층·공용 층·3D 책장)의 구조와 화면을 대신한다. #94(책 종류: 원고 책·모음 책·문서 책, 원고 책 탭, 문서 책, 게시판)는 그대로 쓴다.
> 구현: `src/magus/maps.py`(규칙), `src/magus/store/maps.py`(지도 저장·맞추기·노드·선·연결·인용 점검 범위),
> `src/magus/project_args.py`(도구의 project 인자), `src/magus/category/moves.py`(책 옮기기·지도 바꾸기 문장),
> `src/magus/category/maptext.py`(지도를 글로), `src/magus/webmap.py`·`webmap_assets.py`(웹), `src/magus/export_zip.py`(내려받기),
> `src/magus/map_migrate.py`(이전). 3D 책장(`webfloors.py`)과 층 인자(`floor_args.py`)는 지웠다.
> 화면 문구·도구 문구 전문: `docs/decisions/project-map-texts.md`. **서버 배포 안 함**(묶음 배포 `docs/deploy.md` 2-2절).

## Problem

- 3D로 기울인 책장은 층마다 글자 크기가 달라 읽기 어렵고, 층·책이 늘면 피로하다(사용자 판단).
- 원하는 구조: 프로젝트 → 마인드맵 → 노드 → 책장(정면 2D) → 책 → 게시판(날짜·제목 목록). 노드는 아무 데나 두고, 아무 노드끼리 선을 잇는다.
  여러 프로젝트가 함께 쓰는 것은 공용 층 대신 "다른 프로젝트의 노드를 연결"로 한다. 가운데 노드는 원고 자리지만 원고 없는 프로젝트도 된다.
- 제약
  - 실사용자 공간은 그대로, 이전은 시험 공간 사본에서만. 서버 접속 없음. 서버는 아직 층 이전 전(`p1-profile-email`)이라,
    이전은 층 이전 전 데이터와 뒤 데이터 어느 쪽에서 시작해도 같은 결과여야 한다.
  - 인용 점검 수치(확인·미확인·참고문헌에 없음·미연결)가 이전 전후로 같아야 한다.
  - 도구 29개·도구 목록 10,904토큰 이하, 전체 현황 3,000토큰 이하. 외부 라이브러리·CDN 없음(#56). 주 사용자는 고령의 교수(읽기 쉬움).

## Action

**구조(저장)**
- 프로젝트 = 지금의 작업물(옛 층). 옛 공용 층은 프로젝트 「내 서재」다. 내부 id는 그대로 `common`, 항목 파일의 `"floor"`는
  "그 항목이 속한 프로젝트 id"로 뜻만 바꿨다(층 이전이 적은 값을 그대로 쓴다).
- 지도 = 프로젝트마다 `shelf/maps/<프로젝트>.json`: 노드(id·이름·x·y·색·꽂힌 책 또는 연결 대상)와 선(노드 둘, 방향 없음).
  가운데 노드 id는 `center`(이름은 프로젝트 제목, 원고 책은 여기에만). 노드 40개·노드마다 책 12권·프로젝트 20개까지.
- 책은 노드에 꽂힌다. 기본 책(생각·문체·문헌)은 한 프로젝트에 종류마다 하나라, 항목의 `"floor"`만으로 어느 책인지 정해진다.
  노드 배치만 지도 파일에 있다.
- 연결 노드는 다른 프로젝트의 노드(원본)를 가리킨다. 책을 갖지 않고, 보거나 넣으면 원본에 들어간다. 연결의 연결은 원본으로 잇고,
  같은 원본을 두 번 잇지 않는다. 원본이 사라지면 '원본 없음'으로 남는다.
- **지도 파일이 없으면 지금 배치에서 계산한 지도로 보인다**(읽기는 아무것도 쓰지 않는다): 가운데 노드에 원고·문서 책, 기본 책과 카테고리는
  이름이 같은 노드 하나씩(가운데와 이음), 「내 서재」의 문헌(과, 자기 문체가 없으면 문체)으로 가는 연결 노드. 위치는 가운데를 둘러싼 가로로 긴 타원.
  지도 파일이 있어도 읽을 때 맞춘다(없어진 책은 빼고, 노드에 없는 책은 이름이 같은 노드 또는 빈자리의 새 노드에).
  책이 생기거나 옮겨 오면 그 자리에서 지도 파일에 적는다(놓을 노드를 함께 받는다). 지도를 바꾸는 쓰기 전에는 모든 지도를 먼저 파일로 적는다.

**인용 점검·같은 문헌**
- 원고의 인용 점검이 보는 문헌 = 그 프로젝트의 문헌 + 연결 노드가 가리키는 노드에 꽂힌 문헌(`store.cite_scope`).
- 문헌 key는 사람마다 하나라 같은 key가 두 곳에 있지 않다. 이 원고의 인용 점검이 보지 못하는 다른 프로젝트에만 있는 문헌을
  참고문헌으로 가져오거나 등록하면, 그 문헌을 「내 서재」의 문헌으로 옮기고 **두 프로젝트 지도에 그 노드로 가는 연결 노드를 붙인다**(없을 때만).
  옮긴 기록(시각·원래 프로젝트·이유)은 #93-a처럼 문헌에 남고, 리포트에 "「내 서재」로 옮긴 문헌 N편" 한 줄.
- 문헌 책을 옮기거나 연결 노드를 치워 어떤 원고가 그 문헌을 더는 보지 않게 되면 그 자리에서 알린다(웹 한 줄·도구 응답 '주의').

**이전(층·공용 층·사람 소유 카테고리 → 프로젝트·지도)**
- 작업물 층 하나 → 프로젝트 하나. 원고 책·문서 책 → 가운데 노드. 모음 책 → **이름이 같은 노드 하나씩**(가운데와 이음).
- 공용 층 → 「내 서재」(모음 책은 각각 노드로). 프로젝트가 쓰던 「내 서재」의 문헌(과 문체)은 그 프로젝트 지도에 연결 노드로 자동으로 붙인다.
- `magus maps plan|apply --backup 폴더|revert`(옛 이름 `floors`도 같다). 층 이전 전 데이터면 층 배치부터 적는다. apply는 전후의 항목 수·
  장별 인용 점검·전체 현황 수를 비교하고, 옛 규칙(그 층 + 공용)으로 낸 인용 점검과도 견준다. revert는 `"floor"`를 떼고 floors.json·지도 폴더를 비켜 둔다.

**도구(29개 그대로, 이름 바뀐 도구 없음)**
- `floor` 인자 → `project`(이름·id, 「내 서재」). 넣기: 프로젝트가 하나면 그것, 여럿이면 묻게(서버는 대화를 모른다). 그 프로젝트의 책 →
  연결 노드가 가리키는 같은 책(하나일 때) → 없거나 여럿이면 묻게(이 프로젝트에 새로 두려면 `category_create(name=생각)`로 다시 꽂는다).
- 노드 일은 기존 도구에: `category_create(template=노드|연결 노드, node)`, `category_edit(node, new_name, color, link, unlink, move_to)`,
  `category_trash(node)`. 지도 보기 = `category_list`(프로젝트마다 노드·책·연결·선). 전체 현황에 지도 두 줄(노드·책·연결, 선).
- `category_put`의 `project_id`는 `project`로 합쳤다(같은 이름 가리기·장 연결·생각 넣을 곳). `book_document`의 `floor` → `node`.
- instructions: 규칙 7(용어집에 프로젝트·지도·노드·연결 노드·책장·책·게시판, 쓰지 않는 말에 '층'·'공용'), 8('지도 보여 줘' → category_list),
  12(프로젝트 고르기), 13('책장(이 노드)').

**웹**
- 첫 화면 `/shelf`: 프로젝트 목록(이름·최근 수정·노드 수, 「내 서재」는 끝) + '+ 프로젝트'(원고 올리기 또는 제목만). 모든 프로젝트에서 찾기.
- 프로젝트 화면 `/shelf/p/<프로젝트>?node=&book=&at=&view=`: 지도 + 패널(1200px 이상은 오른쪽, 좁으면 아래). 노드를 누르면 패널에 정면 책장,
  책을 누르면 같은 패널 아래 게시판 자리(iframe)에 그 책 화면. 페이지는 바뀌지 않고 주소가 상태를 기억한다(pushState).
- 지도 조작(스크립트): 노드 끌기(놓으면 위치 저장), 빈 곳 두 번 누르기·'+ 노드'(지도 위에 뜨는 상자), 노드 오른쪽 ＋를 끌어 선 잇기·'선 잇기' 모드,
  선을 눌러 '선 끊기', 휠·두 손가락·빈 곳 끌기로 확대·축소·이동, '가운데로', 확대 ＋/－. 패널의 책을 지도의 노드로 끌어 놓으면 옮긴다.
- 스크립트 없이·키보드로: 노드는 링크(Tab·Enter), '목록 보기'(노드 → 책 → 게시판), 노드 설정(이름·색·선 잇기·끊기·휴지통), 책 설정의 '위치'.
  휴대폰(768px 미만)은 목록이 먼저, '지도 보기'로 지도.
- 내려받기: 프로젝트 하나(`/shelf/p/<프로젝트>/export.zip`) 또는 전체(`/shelf/export.zip`). 노드 = 폴더, 모음 책 = 폴더, 게시판 항목 = 마크다운
  파일(머리에 날짜·제목·작성자), 문헌 = 파일, 원고 = 원본 docx + 장 마크다운 + 확인 요청·결정, 문서 책 = 파일, 지도 = `지도.json`, README.
- 옛 주소: `/shelf?floor=…`·`/shelf?at=…`·`/shelf/floor/…` → 그 프로젝트 화면. 메뉴 이름 '책장' → '프로젝트'.
