## 막힌 것과 해결

- [uv가 없고, 설치한 뒤에도 PATH에 잡히지 않음](../troubleshooting/uv-not-on-path.md): 전체 경로로 실행하고, Desktop은 venv 진입점을 직접 실행하게 했다.
- [같은 초에 일어난 쓰기의 순서가 뒤섞임](../troubleshooting/timestamp-collision.md): 밀리초 단위 + 단조 증가하는 utcnow로 해결했다.
- [Windows 콘솔에서 한글 출력이 깨짐](../troubleshooting/windows-console-korean.md): 서버 stdio에는 문제가 없음을 확인했다(SDK가 UTF-8을 강제한다). 개발 콘솔에서는 `PYTHONIOENCODING=utf-8`을 붙인다.
- 테스트 산식 오류: 35장을 5장씩 나누는 바람에 부가 7개로 계산됐다. 산식을 `(n-1)*8//35+1`로 고쳤다. 사소해서 문서는 따로 쓰지 않았다.
- [Bash 도구의 heredoc에서 `\\`가 `\`로 줄어듦](../troubleshooting/bash-heredoc-backslash.md): 백슬래시가 들어간 소스는 Edit/Write 도구로 고친다.
